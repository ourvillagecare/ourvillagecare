# Our Village Care 🌿

**Privacy-first care coordination for families and caregivers.**

Caring for a loved one means juggling appointments, medications, tasks, paperwork, and conversations across too many places. The Village brings it all into one calm, secure space, so everyone in a person's circle of care stays on the same page.

> *It truly takes a village.*

## What The Village does
- 📅 Shared schedules and appointments for the whole care team
- ✅ Tasks and responsibilities everyone can see and claim
- 💬 Updates and notes in one place instead of scattered texts
- 🔒 Private by design: your family's information stays your family's

## How it's built
| Layer | Tools |
|---|---|
| Web app | Next.js |
| Backend & auth | Supabase |
| Hosting | Vercel |
| iOS app | Capacitor |

## Security approach
- Security and privacy are part of the design from the start, not added later
- Access is limited to the people each family invites
- Automated dependency and secret scanning on every repository
